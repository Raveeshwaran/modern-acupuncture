READY TO EXPLORE

Open the HTML for a device-only demo. Run the included Python server for connected accounts. Public hosting and a clinical security/privacy review are required before real patient use.

Important limits

The standalone HTML stores sample records in this browser only. It is not a secure shared service. The server edition stores records in a shared database but still requires security, privacy, clinical and legal review before real patient use. Email delivery, email verification, automatic password recovery, real calendar integration and compliance certification are not included.

The source ZIP includes deployment instructions and a Dockerfile. A permanent public website URL requires a hosting account and actual deployment; the downloadable HTML link is not a hosted clinical backend.

24 API tests and 13 browser checks passed. Testing does not guarantee no bugs. Read the included test report and source guide for details.
